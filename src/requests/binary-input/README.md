# Binary Input Requests

Everything in this folder is to support injecting Flipbook into an experience using the Binary Input API, part of the [Open Cloud Luau Execution API](https://create.roblox.com/docs/cloud/reference/features/luau-execution).

My hope is this whole folder can get folded into [rocale-cli](https://github.com/Roblox/rocale-cli/) so all the task running/polling/checking logic can stay in a tool better suited to that.
